# FLUX Graphics Geometry Annotation

Open `index.html` in a browser. Click points in the displayed order. Scroll to zoom and Shift-drag (or right-drag) to pan. Undo and reset are available on screen. Export JSON frequently; browser storage is local to the browser and is not a replacement for exports. The initial `annotations.json` is an empty placeholder.
