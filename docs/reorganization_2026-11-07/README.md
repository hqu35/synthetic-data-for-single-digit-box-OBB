# Repository reorganization

- `dependency_graph.md`: dependency graph, classification, and compatibility design.
- `dependency_inventory_before.json`: static import inventory and pre-move output list.
- `pre_move_checksums.json`: SHA-256 hashes for 2,049 source, asset, and result files.
- `validation.json`: post-move validation and existing historical test limitations.
- The four `*_readme.md` files are copies of the worker/shared entry-point documentation.

The actual workers and experiment directories are in the repository, not copied into this report. The 2D-blurry worker retains its 3D Blender implementation. Historical files and prior experiment artifacts have not been deleted.
