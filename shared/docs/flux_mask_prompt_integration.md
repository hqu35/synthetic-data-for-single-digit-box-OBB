# Mask-to-prompt integration and full-boundary FLUX boxes

The mask worker generates its geometry first. The prompt pipeline then validates and reads the same image, strip order, reading, FLUX boxes and original YOLO labels. The prompt receives exactly the number of strips actually produced. The current mask worker supports five strips; six-strip generation is not implemented. The mask contains geometry only: digit identity comes from metadata and rolling state is selected by the prompt seed, not read from image pixels.

For FLUX, each axis-aligned rectangle encloses the complete continuous quadratic strip boundary. Its integer coordinates are `[top,left,bottom,right]` on a 0–1000 full-image grid; top/left are rounded downward and bottom/right upward so quantization cannot cut into the mathematical boundary. Unlike the prior OBB-derived FLUX boxes, the extrema are computed from the strip, including possible extrema on curved sides. `mask/annotations.txt` independently preserves the original class-0 YOLO OBB vertices normalized to 0–1. Antialiased pixels may extend slightly beyond the mathematical contour.

The example reading is `03784`; its fifth wheel is described as transitioning 4 to 5. The layout guide is the last reference after nine appearance references in the existing prompt convention.

`watermeter_generate_layout_prompt.py` generates a matched sample and prompt; `watermeter_geometry.py` rejects mismatched image, metadata, boxes, OBB rows or strip order. The pilot manifest builder now reads native mask samples and uses their reading and geometry instead of importing absent modules. The prompt boxes are textual layout hints, not a guarantee that FLUX will obey them; no FLUX/ComfyUI inference or external service integration was tested. Cropping or padding downstream requires remapping the geometry.

Validation: 12 worker/integration tests passed, including mismatched image/box rejection, original OBB preservation, dense curved-boundary coverage, and 100-row manifest pairing with generated local fixture images. Twenty schema-1 examples and one schema-3 example passed read-only compatibility audits. The included frozen reproduction produced eight sample artifacts identical byte-for-byte. The previous experimental OBB-extents FLUX boxes and corner-only prompt example remain historical; schema 5 is the current full-boundary definition.
