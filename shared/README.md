## Directory overview

Shared assets, configurations, implementation modules, tests, documentation, skills and delivery utilities.

### Files

| File | Role |
|---|---|
| [DELIVERIES.md](DELIVERIES.md) | Historical index of dated external deliveries. |
| [README.md](README.md) | Directory documentation and this managed overview. |
| [delivery\_locations.json](delivery_locations.json) | Recorded external delivery locations. |
| [requirements.txt](requirements.txt) | Python dependency specifications. |

### Subdirectories

| Directory | Role |
|---|---|
| [assets/](assets/README.md) | Reference imagery and the shared photo-derived atlas; consumers must retain the atlas paths. |
| [configs/](configs/README.md) | JSON settings for geometry, rendering, material reviews and past dataset workflows. |
| [digitgen/](digitgen/README.md) | Shared geometry, Blender construction, annotation, appearance and sampling modules. |
| [docs/](docs/README.md) | Project documentation and historical reports; older paths and descriptions may describe superseded workflows. |
| [skills/](skills/README.md) | Repository-local skills used by project instructions. |
| [tests/](tests/README.md) | Host-Python unit tests and Blender-only checks for geometry, optics, sampling and mask/prompt integration. |
| [tools/](tools/README.md) | Repository delivery helper for dated external artifacts. |

### Summary

This directory groups the files and subdirectories described above.
