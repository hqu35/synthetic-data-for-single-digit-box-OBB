# FLUX AABB and YOLO OBB example

See `sample_0001/conditioning.png` for the mask and `sample_0001/preview.png` for contours and FLUX boxes. `flux_bboxes.json` provides integer Y-first AABBs in 0–1000; `annotations.txt` contains original class-0 four-point YOLO OBBs in 0–1. The full geometry is retained in `geometry.json`. Reproduction instructions and frozen source are in `reproduction/`.
